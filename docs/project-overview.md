# Project Overview

This project presents a complete network infrastructure design for a small-to-medium enterprise (SME) office environment.

The organization consists of approximately 50 staff members, with additional guest users and network devices, totaling around 120 active endpoints. The existing network lacks segmentation, centralized management, and scalability.

## Objectives

- Design a scalable and secure wired and wireless network
- Implement VLAN segmentation for traffic isolation
- Provide high-performance Wi-Fi coverage using Wi-Fi 6
- Ensure secure internet access using a Next-Generation Firewall (NGFW)
- Enable centralized monitoring and management

## Key Features

- VLAN-based network segmentation (Staff, Admin, Guest, IoT, Devices)
- Wi-Fi 6 deployment with controller-based management
- High Availability (HA) architecture option
- QoS implementation for voice and video traffic
- Network monitoring using SNMP-based tools

## Technologies Used

- Cisco Catalyst Switching (L2/L3)
- Fortinet NGFW (conceptual)
- VLAN (IEEE 802.1Q)
- 802.1X Authentication
- DHCP, DNS, SNMP
